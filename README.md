# Spotify Listening History Analysis

Welcome to the **Spotify Listening History Analysis** project! This project explores 149,860 Spotify listening records to understand music preferences, listening habits, and playback behavior using Python. It focuses on discovering patterns and trends in music consumption through data analysis and visualization.

## Getting Started

- Load the Spotify listening history dataset using Pandas.
- Explore the dataset structure, columns, and data types.
- Perform data cleaning and preprocessing.
- Convert timestamps and listening duration into appropriate formats.
- Conduct Exploratory Data Analysis (EDA) to identify meaningful patterns.
- Create visualizations to understand listening behavior and trends.

## Features

- **Listening Analysis:** Analyze total listening activity and listening duration.
- **Artist Analysis:** Identify the most frequently played artists.
- **Track Analysis:** Discover the most listened-to songs.
- **Album Analysis:** Explore popular albums based on listening activity.
- **Platform Analysis:** Examine listening activity across different Spotify platforms.
- **Time-Based Analysis:** Identify listening trends by date, month, and year.
- **Playback Analysis:** Analyze track start and end reasons.
- **Shuffle Analysis:** Understand listening behavior when shuffle mode is enabled or disabled.
- **Skipped Track Analysis:** Examine skipped and completed listening sessions.
- **Data Visualization:** Present insights through different charts and graphs.

## Technologies Used

- **Python:** Main programming language for data analysis.
- **Pandas:** Data manipulation, cleaning, and aggregation.
- **NumPy:** Numerical operations and calculations.
- **Matplotlib:** Data visualization and graphical representation.
- **Seaborn:** Statistical visualization and graphical analysis.

## Dataset Information

The dataset contains **149,860 records and 11 columns**, including:

- Track URI
- Timestamp
- Platform
- Listening Duration (ms_played)
- Track Name
- Artist Name
- Album Name
- Reason Start
- Reason End
- Shuffle
- Skipped

## Project Objectives

The main objective of this project is to transform raw Spotify listening history into meaningful insights. By analyzing listening frequency, duration, artist preferences, playback behavior, and time-based trends, the project helps understand how music listening habits change over time.

## Conclusion

This project demonstrates the practical application of Python for data cleaning, exploratory data analysis, statistical analysis, and data visualization. It provides a deeper understanding of personal music consumption patterns and demonstrates how raw listening data can be converted into meaningful analytical insights.
